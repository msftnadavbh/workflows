How to present this demo
        
  1. Ask the audience to choose a failure. Run “Both at once” to show parallel specialists.
  2. Choose “Surprise me” for the new-evidence moment. Point to the failed capacity check and new branch.
  3. Pause, explain the saved steps, then resume. At the review gate, inspect evidence before approving.
  4. Use Native Copilot for actual model calls. If unavailable, say “This is the offline rehearsal: real checks, no LLM.”

        
The feature walkthrough stops automatically at routing, agent explanation, new evidence, checks, and independent review. Use Continue walkthrough; final draft approval is a separate action. Choose Continuous run to skip teaching stops.

        
Keyboard: S run/resume, P pause, V stage view. Shortcuts do not run while editing a field. Pacing includes intentional presentation delays; this is not a performance benchmark.
